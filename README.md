## Features
- Add and delete todos (API integrated)
- Toggle completion status of single or all todos
- Edit (rename) todo titles inline
- Show loader while waiting for API responses
- Error notifications for failed requests

## Technologies used
- React
- TypeScript
- SCSS / CSS Modules
- Fetch API
- React Hooks (useState, useEffect)
- Prettier (code formatting)
