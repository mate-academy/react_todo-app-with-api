# React Todo App with API

Aplicação de gerenciamento de tarefas com integração a uma API REST. Permite criar, atualizar, editar e remover tarefas com persistência de dados.

## Demo

[DEMO LINK](https://Igor-hrm.github.io/react_todo-app-with-api/)

## Funcionalidades

- Listagem de tarefas a partir da API
- Criação de novas tarefas
- Remoção de tarefas individuais
- Marcar/desmarcar como concluída
- Toggle de todas as tarefas
- Edição de título (double click)
- Remoção de tarefas concluídas
- Filtros: todas, ativas e concluídas

## Detalhes técnicos

- Atualizações assíncronas com feedback de loading por item
- Tratamento de erros em operações de API
- Edição com suporte a Enter, Blur e Escape
- Otimização de requisições (evita updates desnecessários)

## Tecnologias

- React
- TypeScript
- REST API
- CSS / SCSS
